# Diario Auto V7.8 — Consolidamento

## Obiettivo
Questa versione consolida il progetto prima di ulteriori funzioni: configurazione, navigazione, dati locali, PWA e preparazione Android devono rimanere coerenti.

## Controlli da eseguire con Node/npm
1. `npm ci`
2. `npm run build`
3. `npm run lint` (se disponibile)
4. test installazione PWA
5. test offline
6. test backup/ripristino
7. test su Android/TWA

## Regole di stabilità
- Non cambiare lo schema IndexedDB senza una migrazione versionata.
- Non duplicare i dati tra dashboard, movimenti e statistiche.
- Le statistiche devono essere derivate dai record salvati.
- Le funzioni avanzate restano accessibili da Altro e non devono sovraccaricare la barra inferiore.
- `assetlinks.json` deve usare il fingerprint SHA-256 reale della chiave Android definitiva.

## Prossima area funzionale
Dopo la verifica della V7.8, priorità a:
- Movimenti realmente unificati;
- filtri coerenti;
- inserimento rapido;
- statistiche derivate;
- gestione scadenze.
