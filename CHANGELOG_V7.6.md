# Diario Auto V7.8 — Backup + PWA

## Obiettivo
Rafforzare la protezione dei dati e l'esperienza PWA/Android senza cambiare il modello dati dell'app.

## Interventi
- Versione applicativa aggiornata a 1.6.0.
- Preparata la base per una gestione più chiara di backup/ripristino.
- Mantenuta la compatibilità con IndexedDB e le funzioni esistenti.
- Aggiornata la nomenclatura V7.5 → V7.8 nei file testuali e di configurazione.
- Nessuna funzione OBD, Drive, Premium, statistiche o manutenzione rimossa.

## Nota
Il fingerprint SHA-256 di Android in `public/.well-known/assetlinks.json` deve essere quello reale della chiave di firma definitiva prima della pubblicazione sul Play Store.
